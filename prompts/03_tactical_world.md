# 03 戦術3Dワールド

あなたは一人称で歩き回る3D世界（作戦区域）の担当です。次の担当（04）がここに狙撃とゾンビを載せます。
狙撃ゲームなので **「遠くまで見通せて、射線と遮蔽が面白い地形」** を軽い描画で実現することが仕事の核心です。

## ゴール（M2 前半）
セルの土地区分に応じた 1km 四方のマップがシードから生成され、一人称で歩き・走り・しゃがみ・伏せができ、昼夜が移り変わる。

## 実装範囲

### A. マップ生成（`src/gen/`、純関数・決定的）
- 入力 `(mapSeed, land, isHome, lootSpots)` → 出力 `TacticalMap`: ハイトマップ 257×257、建物（AABB＋高さ＋種類）、道路、樹木、草むら、岩、探索ポイント、4m 通行グリッド
- 土地区分ごとの性格:
  - **rural**: 緩い起伏、田畑の区画、点在する民家・納屋、あぜ道。見通しが良い
  - **forest / mountain**: 大きな高低差、樹木密、稜線からの撃ち下ろし
  - **suburb**: 格子状の道路、低層住宅が並ぶ、公園・駐車場の開けた場所
  - **urban**: 中高層ビル、大通りの長い射線、屋上に登れる建物（外階段）を数棟
- 必ず **高所の射点**（丘、屋上、鉄塔の足場など）が3か所以上できるようにする
- `isHome` のときは中央 半径120m を平坦化して空ける（建築用地）
- 生成結果を上から見た PNG に書き出すデバッグスクリプトを用意し、4区分すべてを目視確認する

### B. 描画（`src/render/tactical/`）
- 地形メッシュ（頂点カラー）、建物・樹木・草・岩は InstancedMesh、距離カリング
- 空・太陽・月・フォグ・環境光を時刻で遷移。夜は暗いが「何も見えない」にはしない
- 視程 800m。予算: ドローコール < 100（ゾンビ等のぶんを残す）、内蔵GPUで 60fps
- ローポリ＋抑えた彩度の統一した見た目。テクスチャ画像は使わない（必要ならプロシージャルな DataTexture）

### C. プレイヤー移動（`src/sim/tactical/player.ts`）
- `InputFrame` から移動・視点・姿勢を更新。歩き 1.6 / 走り 5.0 / しゃがみ 1.0 / 伏せ 0.4 m/s、スタミナ消費
- 地形追従、建物 AABB との衝突、急斜面の制限、外階段・はしごで屋上へ
- カメラ高さは姿勢で変化（1.7 / 1.0 / 0.3m）、切替は滑らかに
- 射撃・スコープは **実装しない**（04）。ただしカメラの FOV を外から変えられる口と、視線レイ（原点・方向）を得る関数は用意する

### D. 衝突・照会の共通関数（`src/sim/tactical/collision.ts`）— 04 と 06 が使う
- `raycastWorld(map, origin, dir, maxDist)` → 地形 / 建物への最初の交差
- `segmentHitsStatic(map, a, b)`、`heightAt(map, x, z)`、`isWalkable(map, tx, ty)`
- 空間ハッシュ（16m）への動的オブジェクト登録の仕組み
- テスト: 既知の配置でのレイキャスト結果、決定的生成（同シード同マップ）

### E. セル遷移
- マップを用意する契機は3つ: **開始地点の決定後**（`beginAt` の直後）、**移動の到着時**（`travelArrived`）、**ロード後**。移動中に通過するだけのセル（`cellEntered`）では生成しない
- 移動開始（`travelStarted`）で `state.tactical` を `null` にし、到着時に作り直す（ロード表示）。開始位置は、本拠セルなら中央、それ以外はマップ端の道路上

## やらないこと
ゾンビ、武器、スコープ、耳、建築物の描画、生存者。HUD は方位と姿勢表示だけ。

## 受け入れ基準
- 4つの土地区分それぞれで、歩いて高所に登り、数百m先まで見渡せる（スクリーンショットを撮って自分で確認する）
- 建物・木をすり抜けない、地面に埋まらない、落下で動けなくならない
- 同じセルに入り直すと同じ地形になる
- 800m 視程で 60fps 相当（Playwright で数秒間のフレーム時間を計測して PROGRESS.md に数値を書く）

## 追加の指示（01・02 の結果を受けて）

- **02 のブランチの上で作業する**（02 は完了済み。`main` に入っていなければ先に取り込む）
- 土地区分は `ctx.grid.cells[cell].land`、探索ポイント数は `sim/world/derive.ts` の `cellTactical(state, grid, cell).lootSpots` から取る。`mountain` セルにも入れる（移動コストが高いだけ）ので5区分すべてで生成できること
- `mapSeed` は `state.seed` とセル番号から決定的に導く（同じゲームで同じセルに入り直すと同じ地形）
- **`TacticalMap`（ハイトマップ・建物・通行グリッド）は `GameState` に入れない。** セーブは世界セルだけで約 650KB ある。`mapSeed` から再生成してメモリに持ち、sim と render の両方がそれを参照する。`state.tactical` に置くのは §5 のフィールドだけ
- セーブは `core/save.ts` の `packState` が zombies / corpses / bullets を落とす。ロード後は「`state.tactical` はあるがマップが未生成」の状態から復元できるようにする（`lootSpots[].taken` は保存されるので、再生成したマップに重ねる）
- 描画は 01 の仮実装を置き換える: `renderer.unregister('ground')` と `'camera'`。空・フォグ・光は `render/sky.ts` が既にあるので、作り直さず太陽・月などを足す形で拡張する
- 移動中は戦術モードに切り替えられない（`setMode` が `travelling` で拒否される）。e2e は「新規ゲーム → タイムラプス → 候補選択」の開始手順になっているので、それに合わせて追加する
