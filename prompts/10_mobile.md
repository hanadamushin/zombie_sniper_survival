# 10 スマホ対応（任意・低優先）

あなたはスマートフォン（タッチ操作）対応の担当です。PC 版が完成している前提で、
**PC 版の挙動を一切変えずに**、タッチでも一通り遊べるようにします。完璧な操作性よりも「破綻なく遊べる」を目標に、小さくまとめてください。

## 読むもの
- `CLAUDE.md`、`docs/PROGRESS.md`
- `src/input/**`、`src/ui/**`
- `docs/04_architecture.md` §6（`InputFrame`）

## ゴール（M8）
スマホの横画面で、狙撃・回収・指揮・地図の全操作ができる。

## 実装範囲
1. **入力層**: タッチ入力から同じ `InputFrame` とコマンドを生成する（sim 側は変更しない）。端末判定はポインタ種別で行い、PC とは自動で切り替える
2. **戦術層の操作**
   - 左: 仮想スティック（移動）／右: ドラッグで視点
   - ボタン: スコープ（トグル）、射撃、息止め（押している間）、リロード、姿勢切替、ナイフ、回収
   - スコープ中の視点感度は倍率に応じて下げる。微調整用に **ジャイロ照準**（任意でオン、許可ダイアログ対応）
   - 倍率はスライダー、ゼロインは ± ボタン
   - 照準補助は入れない（狙撃の手応えを保つ）。代わりに息止めの効果時間をタッチ時のみ +30%
3. **指揮層・戦略層**: ピンチでズーム、ドラッグでパン、タップで選択、長押しで詳細。壁・堀の線引きはドラッグ。パネルは下からのシート表示
4. **レイアウト**: 横画面固定の案内（縦のときは回転を促す）、セーフエリア対応、ボタンは 44px 以上
5. **性能**: 画質プリセット「低」（視程 500m、草なし、同時ゾンビ 60、解像度スケール 0.75）を自動適用。設定で変更可
6. **PWA（余力があれば）**: manifest とアイコン（コード生成）、全画面表示

## やらないこと
- ゲーム内容・バランスの変更、PC 操作の変更、ネイティブアプリ化

## 受け入れ基準
- Playwright のモバイルエミュレーション（横向き）で、新規ゲーム → 1体狙撃 → 耳回収 → 指揮層で柵を1本配置、が通る
- PC での `npm run check` と e2e が引き続き通る（PC の挙動が変わっていない）
- モバイル相当の設定で 30fps 以上（計測値を PROGRESS.md に）
