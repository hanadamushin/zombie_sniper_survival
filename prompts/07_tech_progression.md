# 07 技術ツリー・進行

あなたは技術ツリー（研究、時代、排他分岐）と、ゲーム全体の進行（勝利・敗北・難易度）の担当です。
すでに各システムに散らばっている「技術で変わるはずの値」を、1つの仕組みで束ねるのが主な仕事です。

## 読むもの
- `CLAUDE.md`、`docs/PROGRESS.md`（全員分。どの値が技術待ちで仮置きになっているかを拾う）
- `docs/03_tech_tree.md`（全部）
- `docs/02_systems_spec.md` §9、`docs/01_game_design.md` §12・§13
- `docs/04_architecture.md` §5（`ResearchState`）

## ゴール（M5）
研究担当を置くと各カテゴリが時間経過で進み、分岐で二者択一を迫られ、取得した技術がゲーム全体に効き、建国宣言で勝利できる。

## 実装範囲

### A. 技術データ（`src/data/techs.ts`）
- `03_tech_tree.md` の全ノード: id、カテゴリ、時代、費用、前提（AND / OR）、排他相手、効果
- **効果は宣言的に書く**。種類の例:
  - `unlock`: 建物・武器・仕事・コマンドの解禁
  - `modifier`: `{ key: 'wall.hp', op: 'mul', value: 1.5 }` のような数値修飾
  - `flag`: 個別ロジックが参照する真偽値（例: `moat.noFill`, `scope.rangefinder`）
- テスト: 前提が循環していない、存在しないIDを参照していない、全ノードが到達可能（排他を考慮して、各分岐のどちらを選んでも詰まない）

### B. 修飾の解決（`src/sim/research/modifiers.ts`）
- `getMod(state, key, base)` — 取得済み技術・建物・特性・難易度からの修飾をまとめて適用して返す。結果はキャッシュし、技術取得時などに無効化
- 既存システム（04 武器、05 作業量・賃金・食料、06 耐久・工数・解禁判定）の該当箇所を `getMod` / `isUnlocked` / `hasFlag` 経由に置き換える。**これが本セッション最大の作業**。置き換えた箇所を PROGRESS.md に一覧で残す
- 03_tech_tree.md の効果のうち、挙動の追加が必要なもの（跳ね橋、自動銃座、民兵制、狙撃班、測距表示、暗視、感染予測表示、無線による来訪、駐屯地の自律成長など）を、担当システム内に最小限の実装で追加する。大きすぎるものは仕様を簡略化してよいが、**分岐の両側が同程度に魅力的** であることは崩さない

### C. 研究の進行（`src/sim/research/index.ts`）
- 05 が公開した研究 output を、カテゴリ配分比率で各カテゴリの進行中ノードへ加算（1時間ごと）
- `startResearch` / `setAllocation` コマンド。進行中ノードが無いカテゴリの RP は他カテゴリへ再配分
- 排他分岐: 取得時に相手側とその後続を `locked` へ。**選択前に確認ダイアログ**（両者の効果と、失うものを並べて表示）
- 時代の進行（当該時代のノード合計6個）、`eraAdvanced`

### D. 研究 UI（`src/ui/command/research.tsx`）
- 5カテゴリ × 4時代の表形式ツリー。前提の線、状態（取得済 / 進行中 / 取得可 / 未解禁 / 封鎖）、進捗バー、残り日数の見込み
- 配分スライダー（合計100%を保つ）
- 分岐ノードは対で表示し、封鎖された側は取り消し線で残す（選択の重みを見せる）

### E. 勝利・敗北・難易度（`src/sim/research/victory.ts`）
- 建国宣言の条件判定と進捗表示（人口・駐屯地数・地方数・到達技術・政府庁舎）
- 到達技術ごとのエンディング（短いテキスト＋統計: 日数、討伐数、ヘッドショット率、生存者数、失った人数）。勝利後も継続可能
- 敗北画面（原因と統計）
- 難易度3段階の係数を `getMod` に統合

### F. テスト
- ヘッドレスで「研究担当4人・配分均等」で回し、各時代への到達日数を出力（目安: 定住期 15日、再建期 45日、復興期 90日 前後。大きく外れるなら費用を調整して docs を更新）
- 排他分岐の封鎖、修飾の合成順（加算 → 乗算）、キャッシュ無効化

## やらないこと
見た目の統一、音、チュートリアル（08）。全体バランスの本格調整（09）。

## 受け入れ基準
- 研究を進めると鉄板壁が建てられるようになる、などの解禁が実際に機能する
- W5（大口径 / 半自動）を選ぶと、射撃の挙動が明確に変わり、もう片方は取れなくなる
- デバッグ用の「全解禁」フラグ無しで、新規ゲームから木柵 → 土塁 → 鉄板壁の順に進められる
- デバッグコマンドで条件を満たすと建国宣言 → エンディングが出る
- データ整合性テストが `npm run check` に入っている
