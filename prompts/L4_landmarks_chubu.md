# L4 名所: 中部

実在の日本地図（R0〜R8）の上に、各地の主要な観光名所を外観だけで作って置きます。あなたの担当は **中部** です。

## 作業の前提（毎回最初に確認。発注者の許可済み）

- このセッションは GitHub リポジトリ `hanadamushin/zombie_sniper_survival` へ**プッシュできる状態**で作業する。作業ディレクトリにリポジトリが無い、または読み取り専用でしか複製できない場合は、**最初に**リポジトリを書き込み権限つき（push）でセッションに追加し、複製してから作業を始めること。**発注者はこの追加とプッシュを事前に許可している**（このプロンプト自体が発注者からの指示）
- 作業の最後に、指定のブランチへプッシュしたうえで、`git ls-remote` でリモートのブランチがローカルのコミットと一致することを確かめてから終える。プッシュできないまま終えない
- e2e の前に `pkill -f "vite preview"` を実行する（古いサーバが古いビルドを返すことがある）。e2e は全件で 1 時間を超えるので、流すのは名所の spec と `e2e/realmap*.spec.ts` だけでよい（全件は取りまとめ役が流す）

## 名所の約束（L1〜L8 共通）

発注者の要望: 「各地の主要な観光名所は再現したい。建物の中に入れる必要は無い（有事には避難所になって真っ先に終わるはずなので）」

- **外観だけ** の建物を、07d の設計図の形（`src/gen/buildings/`、three を使わない純粋なデータ）で作る。中には入れない。扉は閉じたまま。当たり判定は外形（弾・視線・人を止める）
- **実寸の高さと形**（スカイツリー 634m、東京タワー 333m、城の天守と石垣など）。区域は 10km を 1/10 に縮めた縮図だが、建物は実寸の約束（07d・R0）どおり。足元の広がりが区域に収まらないもの（大きな公園・敷地）は、主役の建物と周りの数点（門・塔・橋）だけにする
- **ひと目でそれと分かる** ことを最優先にする: 輪郭・比率・色・特徴的な部分（スカイツリーの断面が三角から円に変わる形と展望台 2 つ、東京タワーの赤白と展望台、城の天守の屋根の重なり、東京駅の赤レンガとドーム…）。細部より遠目の形
- **遠くからも見える**: 名所は「遠くは箱」の段階を使わず、霧の範囲まで外観で描く（高い塔は区域の外からも見える目印になる）。そのため三角形は 1 つあたり外観 6,000 以下（大きな塔・城は 8,000 まで可、PROGRESS.md に理由）
- **登って撃てる名所**（任意）: 展望台や天守の最上階の外周など、外から登れる足場があれば射点にしてよい（中には入れないので、外階段・はしご・外周の回廊で）
- **廃墟の雰囲気**: 崩壊から 90 日後。窓の割れ、焦げ跡、倒れた案内板、周りに放置された車・避難所の跡（テント・土嚢・救援物資の箱）を 1〜2 点。名所そのものは形が分かる程度に保つ（崩しすぎない）
- **扱いの注意**:
  - **テーマパークは名前・ロゴ・キャラクター・特定のアトラクションの形を使わない**。「湾岸のテーマパークの廃墟（名称なし。西洋風の城・観覧車・ジェットコースターのレール・入場ゲート）」のような一般的な形にする（商標と著作物を避けるため）
  - **慰霊・追悼の施設（原爆ドーム、平和祈念像、戦没者の慰霊施設など）と、政治的な議論のある施設は作らない**。ゾンビの廃墟としての表現がそぐわないため
  - 名所の名前（地図や HUD に出す名称）は正式名称で `ja.ts` に置く
- **置き場所**: 実在の緯度経度を、そのセルの区域の中へ縮めた位置。区域のデータの施設の点に名前があればそれに合わせる。周りの町並み・道路は自動で避ける（重なる建物を取り除く）。高さの基準は区域の地形
- **戦略地図**: 名所のあるセルに印と名称を出す（凡例に「名所」）

## 確認
- 各名所を、地上 150〜300m の距離と、高所（または上空）から撮ったスクリーンショットで、実物の写真の記憶と比べて「それと分かるか」を自分で判定する。分からないものは形を直す
- 全名所を並べた試験用の地図（`?landmarks=1` など）で、性能 3 指標（ドローコール・三角形・sim＋描画発行）を計測する。実際の区域では、名所の最も多いセル（東京の都心など）で計測する
- カタログの自動検査のうち「入れる・探索できる」は名所には当てはまらないので、名所は外観の検査（決定性・三角形・足元が敷地に収まる・当たり判定が外形と一致）だけを受ける

- 一覧の名所（外したものは理由つき）が、実在の位置を縮めた場所に建ち、遠目にそれと分かる（スクリーンショットを PROGRESS.md に列挙）
- 戦略地図に印と名称が出る
- 性能 3 指標が予算内（ドローコール < 150、三角形 < 50 万、sim＋描画発行 < 4ms）
- `npm run check`・`npm run build` が通る
