# L9 橋の名所を端から端まで

発注者の要望: 「橋（レインボーブリッジなど）の名所は、簡略化して一部だけ表示すると不自然なので、端から端までデフォルトの橋と置き換えるようにしてほしい。例えばレインボーブリッジの場合、特徴的な支柱・ワイヤー構造を一つだけ設置するのは不自然なので、ちゃんと二つ設置してほしい」

今の橋の名所は、主塔 1 本と桁 100m ほどを区域の橋の横に置いただけです（青森ベイブリッジ・レインボーブリッジ・明石海峡大橋の主塔など）。区域の橋そのもの（R0 の「土手」＝水面の上の盛り土の道）はそのまま残っていて、名所と並んで立っています。
あなたの仕事は、**名所の橋を、区域の橋の線に沿って端から端まで、実物と同じ構成（主塔・ケーブル・アーチの数）で作り、区域の橋と置き換えること** です。

## 対象
L1〜L8 で作った橋の名所すべて（PROGRESS.md から一覧を作る）。少なくとも次を含む:
- レインボーブリッジ（吊り橋、主塔 2 本・メインケーブル・2 層の桁）
- 青森ベイブリッジ（斜張橋。実物の主塔の数とケーブルの張り方に合わせる）
- 明石海峡大橋（吊り橋、主塔 2 本）
- 錦帯橋（5 連の木のアーチ）、角島大橋、祖谷のかずら橋、はりまや橋、伊勢神宮の宇治橋 など L4〜L8 で作った橋
一覧にない有名な橋で、区域に橋のデータがあり発注者が知っていそうなもの（瀬戸大橋・来島海峡大橋・大鳴門橋・関門橋など）は、余力があれば同じ形で足す（足したものは PROGRESS.md に）

## 作り方
1. **区域の橋のデータを置き換える**: 区域データの橋（R0 の土手、`railState`・道路の橋の区分）のうち、名所の橋にあたる区間を見つけ、その区間の土手を消して、名所の橋の桁を同じ線（両端の道路につながる位置と高さ）に架ける。プレイヤー・ゾンビ・生存者が端から端まで歩いて渡れ、両端の道路とつながっていること。鉄道が通る橋（レインボーブリッジのゆりかもめなど）は線路も桁に載せる
2. **構成は実物どおり**: 主塔・アーチ・径間の **数** は実物と同じにする（レインボーブリッジなら主塔 2 本、錦帯橋ならアーチ 5 つ）。一部だけ置いたり、数を減らしたりしない
3. **縮尺の扱い**: 区域は水平 1/10 なので、橋の長さは区域の水面の幅（縮めた長さ）に合わせる。高さを実寸のままにすると細長い塔が密集した不自然な形になるので、**全体の縦横の比率が実物に近く見えるよう高さも縮めてよい**（桁下の高さは船が通れる程度、主塔は遠目に形が分かる高さ）。決めた比率と理由を PROGRESS.md に書く
4. **名所の橋の作り方を共通の部品にする**: 吊り橋・斜張橋・アーチ橋・桁橋を、「両端の点・径間の数・主塔の高さ」などから組み立てる部品（`src/gen/buildings/defs/landmark/common.ts` か新しいファイル）にし、個々の橋はその設定だけにする。三角形の上限（大きな名所 8,000）を守る。長い吊り橋はケーブルを少ない部品で表す
5. **今の部分的な名所を置き換える**: L1〜L8 が置いた「主塔 1 本と桁の一部」は消し、新しい橋に替える。名所の表（`src/data/landmarks/*.ts`）は、橋の名所を「区域の橋の区間（両端の緯度経度か、区域データの橋の線の id）」で指定できる形にする
6. **橋の名所でない普通の橋**（R0 の土手）はこのセッションでは変えない。ただし、名所の橋と同じ部品で「普通の桁橋」も作れるようにしておき、土手を桁橋に替えるかは発注者の判断として PROGRESS.md に提案を書く

## 確認
- 各橋を、横（橋の全体が入る距離）・上空・橋の上の 3 か所から撮って、実物の写真の記憶と比べ、主塔・アーチの数と形が実物どおりか判定する（PROGRESS.md に表で）
- e2e: 各橋を端から端まで歩いて渡る（プレイヤーが落ちない、両端の道路に出られる）。ゾンビが追って渡ってくる
- 性能 3 指標が予算内（橋のあるセルのうち最も重いところ、橋の上と岸から）
- `npm run check`・`npm run build`・名所の e2e と、橋のある地方の `realmap_*` e2e が通る
