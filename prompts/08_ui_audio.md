# 08 UI/UX・音・チュートリアル

あなたは体験の仕上げ担当です。ここまでの担当は機能優先でパネルを作っています。
それらを **1つのゲームとして統一された見た目と操作感** にまとめ、音を付け、初見のプレイヤーが迷わないようにします。

## 読むもの
- `CLAUDE.md`、`docs/PROGRESS.md`（全員分）
- `docs/01_game_design.md`（全部。トーンと体験の柱を把握する）
- `docs/04_architecture.md` §9、§6（イベント一覧 — 音と通知のトリガー）
- 既存の `src/ui/**` を全部見てから着手する

## ゴール（M6）
何も知らない人が起動して、説明を読まずに最初の1体を狙撃し、耳を拾い、最初の生存者を雇い、柵を建てるところまで到達できる。

## 実装範囲

### A. ビジュアルの統一
- デザイントークン（色・余白・書体・角丸・影）を CSS 変数で定義し、全パネルに適用
- トーン: 乾いた終末。くすんだ紙・カーキ・錆・血の暗赤をアクセントに。装飾過多にしない。軍用の野帳・作戦図のような質感
- 戦術 HUD は **最小限で視界を塞がない**。スコープ中はさらに減らす（弾数・息・ゼロイン・倍率のみ）
- 指揮層: 画面下にメニューバー、パネルは左右ドッキング、俯瞰ビューを隠しすぎない
- 数値の変化（耳 +2、賃金支払い、資源増減）は小さなアニメーションで示す
- 幅 360px〜4K まで破綻しないレイアウト（タッチ操作の実装は不要）

### B. 情報設計の見直し
- 生存者一覧: 並べ替え・絞り込み、仕事別の人数サマリー、適性の高い仕事のおすすめ表示
- 「いま何が問題か」を示す警告欄（食料あと◯日、未払い、壁の損傷、堀の詰まり、感染者、弾薬不足）
- 通知トースト（イベント駆動）と履歴ログ。襲来警告は目立たせる（方角つき）
- 戦略地図の凡例、セル情報カード、移動・遠征・駐屯地設置の導線
- 建築メニュー: カテゴリ分け、コスト・効果・解禁条件のツールチップ
- 設定画面: マウス感度、スコープの押下/トグル、視野角、音量、画質（視程・影）、キー配置の表示

### C. 音（`src/audio/`、Web Audio による合成のみ）
- 射撃（サプレッサの乾いた音＋ボルト操作）、遠距離着弾の遅れた音、ヘッドショットの手応え音、空薬莢
- 足音（地面の種類）、呼吸と息止めの心音、ナイフ
- ゾンビのうめき（距離減衰・方向）、壁を叩く音、破壊音
- 環境: 風、虫、夜の静けさ、雨（天候があれば）。都会と田舎で変える
- UI 音、襲来の警鐘、建設完了、研究完了
- 音楽は不要（入れるなら無音に近いドローンを拠点で薄く）。**静けさ自体が演出**
- 初回のユーザー操作で AudioContext を開始する

### D. チュートリアルとガイド
- 強制的な長文説明はしない。**状況に応じた1行ヒント** を段階的に出す方式（`flags` で既読管理）
  1. 移動 → 2. スコープと息止め → 3. 測距とゼロイン（最初の標的は約150m） → 4. 耳の回収 → 5. 生存者との出会いと雇用 → 6. 仕事の割り振り → 7. 最初の柵と夜の接近 → 8. 研究の開始 → 9. 地図と遠征 → 10. 駐屯地
- 目標表示（「次にやること」1〜3件）。建国宣言までの進捗を常に辿れる
- ゲーム内ヘルプ（操作一覧、ステータスと仕事の対応表、ゾンビ図鑑、弾道の読み方）
- 一時停止メニュー、セーブスロット、タイトル画面の仕上げ

### E. 演出
- 被弾・感染・低体力の画面効果、死亡と復帰の遷移
- 時代が進んだとき・建国宣言の演出（短く）
- ヘッドショット時のごく短いヒットストップなど、狙撃の気持ちよさを底上げする演出（やりすぎない。スローモーションの常用は不可、遠距離キルのみ任意）

## 進め方の注意
- sim のロジックは変更しない（表示のために必要な読み取り用セレクタの追加は可）。バグを見つけたら、**小さく明白なものは直し、大きいものは PROGRESS.md に記録** する
- 各画面を Playwright でスクリーンショットに撮り、自分で見て直す、を繰り返す

## 受け入れ基準
- 新規ゲームからヒントだけを頼りに、上記 1〜7 を通しで進められる（自分で通しプレイして確認）
- 全パネルが同じ見た目のルールに従っている
- 主要イベントすべてに音か通知がある（イベント一覧と突き合わせた対応表を PROGRESS.md に）
- 幅 360px と 1920px のスクリーンショットで崩れがない

## 追加の指示（01〜04 の結果を受けて）

- 04 が出している音・演出用イベントの一覧は PROGRESS.md の 04 の節にある（`shotFired{scoped}`, `dryFire`, `bulletHit{part, surface, range, killed}` など）。着弾音の遅れは `range` から計算する
- **HUD のゲージ（息・回収・スタミナ）は 10Hz の UI 同期だと動きが粗い。** 毎フレーム動かすものは Preact の再描画に乗せず、要素を直接更新する仕組みにする
- 弾の軌跡と銃口の演出が無い。E に、ごく薄い軌跡（スコープ中に自分の弾が見える程度）と発砲時の小さな揺れ・煙を足す
- 設定の「画質」には 04 の解像度自動調整（`RENDER.resolution`、`renderer.setAutoResolution`）のオン／オフと固定スケールを含める。実 GPU では誰も確認できていないので、既定は自動のまま
- 戦略地図・オープニング（`src/ui/world/`）、戦術 HUD、射撃場（`?range=1`）は既にある。作り直さず、見た目の統一と導線の整理にとどめる

### 05 の結果を受けて

- **序盤の即敗北を和らげる。** 生存者が1人もいない状態でプレイヤーが死ぬと敗北になる（設計どおり）が、初日に起きると初見のプレイヤーはそこで終わる。敗北画面に「直前のオートセーブから再開」を置き、`flags.defeat` が立った後はオートセーブを上書きしないようにする（sim の敗北規則自体は変えない）
- ログ（`colony.log[].text`）は表示文ではなく `ja.ts` のキー＋パラメータで保存されている。文言を直すときはキーを消さず中身だけ変える（消すと古いセーブのログがキー名で表示される）
- 05 の音・演出用イベントは PROGRESS.md の 05 の節にある。指揮層パネルは `src/ui/command/`（60 行の一覧は行ごとにメモ化済み。作り直すときも 10Hz で全行を再生成しないこと）

### 06 の結果を受けて

- 建築 UI は機能優先（`ui/command/build.tsx`、スタイルは `ui/styles.css` 末尾）。指揮層のパネルが画面下半分を覆うので、建築中は拠点が隠れやすい。パネルの配置（横置き・折りたたみ）は見直してほしい。視点とカーソルは `core/view.ts` の `commandView`
- 襲来の HUD は上部バーの 1 行だけ（`Hud.tsx` の `RaidAlert`）。方角は文字のみで、画面上の矢印やミニマップはない
- 音・演出用のイベント: `hordeWarning`, `hordeArrived`, `raidStarted{kind, size, dir, away}`, `raidEnded{repelled}`, `structureDamaged`, `structureDestroyed{def}`, `structureBuilt{def}`, `blueprintPlaced`, `structureRemoved`, `moatBridged`, `defenderFired{pos, target, hit}`（曳光線は `render/tactical/structures.ts` が描いている）, `survivorHurt`, `outpostFounded`, `outpostLost`, `outpostSupplied`, `defeat{reason}`
- 堀は地面を掘り下げていない（暗い面＋土の縁で表現）。門は格子で、開閉アニメーションはない。塔の上の防衛担当は立っているだけ（射撃の姿勢なし）
- チュートリアルで必ず伝えること: 防衛担当は **塔の上からしか壁越しに撃てない**／司令部が壊れると敗北／堀は切れ目を 1 か所残すと列ができる

### 07 の結果を受けて

- 研究タブは `ui/command/research.tsx`（機能優先。スタイルは `ui/styles.css` 末尾の「research tab」）。ツリーは 10 列 × 5 カテゴリの固定配置（`POS` の表）で、狭い画面では枠の中で横スクロールする。配置を変えるなら `POS` を直す（テストが「全ノードに位置がある・重ならない」を見ている）
- エンディング／敗北画面は `ui/components/modes.tsx` の `EndingOverlay` / `DefeatOverlay`（統計は `StatList`）。演出はなく文字だけ
- 音・演出用のイベント: `techCompleted{id}`, `eraAdvanced{era}`, `victory{tech}`。研究完了・時代の進行は今はログとトーストだけ
- **新規ゲームで建てられるのは木柵・木の門・テントだけ**になった。チュートリアルの「建築」の前に「研究担当を置く → 土木の基礎（F1）」の導線が要る。雇用候補の能力は C2（勧誘）を取るまで見えない。医療の仕事は S4 から。人口は C5（行政）まで 30 人が上限
- スコープ内の表示（`.scope-info`: 測距・見越し・ゾンビの種類と体力）は 10Hz の UI 同期のまま。暗視（W7）は夜のスコープ中に環境光を緑に上げるだけの簡易表現（`render/sky.ts`、`RENDER.sky.nightVision`）
- 戦略地図の「7日後の予測」（S7a）はゾンビ表示のときだけ出るトグル。凡例や注記の整理は未着手
