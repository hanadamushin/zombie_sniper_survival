# 04 狙撃・ゾンビ戦闘

あなたはこのゲームの核である **スコープを覗いての精密狙撃** と、ゾンビ、耳の回収の担当です。
発注者は「スコープを覗いて精密射撃をするゲームが好き」と明言しています。ここの手触りがゲームの価値を決めます。
仕様を満たすだけでなく、**自分で撃ってみて気持ちよいか** を何度も確かめて調整してください。

## ゴール（M2）
作戦区域でゾンビを見つけ、スコープで測距・照準し、弾道を読んで撃ち、歩いて耳を回収する、という一連が遊べる。

## 実装範囲

### A. ライフルと弾道（`src/sim/tactical/weapon.ts`, `ballistics.ts`）
- 弾は発射体。初速・重力・簡易空気抵抗、1ステップ4サブステップ、線分判定。飛翔時間があるので動く的には見越しが要る
- ゼロイン（100/200/300/400m）: その距離で照準線と弾道が交わるよう発射角を補正
- ボルト操作・弾倉・リロード、空撃ち、所持弾薬の消費
- 貫通（2体、2体目 60%）。風は `difficulty` とフラグで有効化できるよう実装し既定は無効
- 武器定義は `data/weapons.ts`。技術による派生（大口径・半自動・光学・弾薬）を後で差し替えられる構造にする（07 が使う）
- テスト: 各距離での落下量が解析値と一致、ゼロイン距離で照準点に着弾、貫通

### B. スコープ（`src/render/tactical/scope.ts` ほか）
- 右クリックで覗く（0.25秒の遷移）。倍率 4〜12、ホイールで変更。FOV を倍率に正確に対応させる
- **ミルドットレティクル**: 目盛りが実際の角度（1 mil）と一致すること。倍率を変えても目盛りの意味が変わらない方式（第一焦点面）で実装し、目盛りで測距・落下補正ができる
- 円形マスク、周辺の暗がり、覗き位置のずれによる影（軽い演出）
- 揺れ: §3.3 の式。姿勢・移動直後・疲労・息止め。揺れは滑らかなノイズ（ランダムな震えではなく、呼吸のような8の字＋微細動）
- 息止め（Shift）: ゲージ表示、切れたときのペナルティ
- 射撃時: 反動でレティクルが跳ねる → 戻る。着弾は遠距離ほど遅れて見える。**着弾点に土煙／血煙** を出し、外したときにどこへ外れたか分かるようにする
- 非スコープ時は照準点なし（腰だめは不正確）

### C. ゾンビ（`src/sim/tactical/zombies.ts`、`src/render/tactical/zombies.ts`）
- 4種類（§3.4）。状態機械: 徘徊 → 警戒 → 追跡 → 攻撃 → 倒れる
- 知覚: 視認距離・視野角・遮蔽（`raycastWorld`）、仲間の死体を見たときの警戒。銃声には反応しない
- 部位判定: 頭（球）・胴（カプセル）・脚（カプセル）。脚を撃つと転倒して這行化
- 出現: 02 の導出関数から active 上限と比率を得て配置。倒したら `world.cells.Z` を減らす。マップ端からの補充
- 移動は当面、目標へ直進＋障害物回避でよい（拠点へのフローフィールドは 06）
- 描画: 部位別 InstancedMesh、歩行・走行・這う・被弾のけぞり・倒れる動き。**遠距離（300m+）でも種類と向きがシルエットで判別できる** こと
- ヘッドショットは明確に分かる演出（倒れ方の違い＋音は 08 だがイベントは発火）
- 150体同時で 60fps を維持（遠方は更新頻度を落とす LOD）

### D. 耳・ナイフ・被ダメージ
- 死体の生成と期限、E 長押しで耳を回収（進行ゲージ）、`earsCollected` イベント、`player.inv.ears`
- ナイフ: 正面/背後の判定、振りの間隔
- プレイヤーの被ダメージ、感染判定、死亡（復帰処理は 05 が共同体側とつなぐので、ここは `playerDied` の発火と仮の再開まで）

### E. HUD（最小限。見た目の仕上げは 08）
- 弾倉/所持弾、姿勢、息ゲージ、ゼロイン距離、倍率、所持耳、HP、回収可能な死体の方向の目安

### F. 調整用の射撃場
- デバッグフラグで、既知距離（100〜600m、100m刻み）に静止標的と歩行標的を並べたテストマップを開けるようにする。ここで弾道・揺れ・レティクルを目視検証する

## 手触りの確認項目（自分で遊んで判断すること）
- 伏せ＋息止めで 400m のヘッドショットが「狙えば当たる、雑だと外れる」難度か
- 立ち撃ちは近距離以外あてにならないか
- 目盛りで落下を見越す操作が成立しているか（ゼロインを変えずに 300m を撃てるか）
- 撃ってから倒れるまでの「間」が気持ちよいか
- 回収に歩く時間が退屈すぎないか（死体までの誘導、歩行速度）

違和感があれば `data/balance.ts` と `docs/02_systems_spec.md` を直してよい。変更理由を PROGRESS.md に残すこと。

## やらないこと
生存者、建築物、襲来、技術による武器派生の解禁処理、音。

## 受け入れ基準
- 射撃場で各距離の着弾が仕様どおり（テスト＋目視）
- 田舎セルで 10 体ほどを狙撃し、歩いて耳 20 を回収できる
- 都市セルで囲まれると普通に死ぬ
- 150 体出しても 60fps 相当（計測値を PROGRESS.md に記録）
- 弾道・判定のテストが `npm run check` に入っている
