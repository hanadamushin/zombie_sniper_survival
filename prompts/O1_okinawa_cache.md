# O1 沖縄と軍艦島の秘蔵の補給基地と、それを伝える手がかり

発注者の要望: 「沖縄は鹿児島から渡れるならそのままで良い。ただ沖縄へ行くメリットが薄いので、弾薬 100,000 発、耳 10,000、最強の生存者（雇用は格安、能力は圧倒的に高い）など、圧倒的なメリットになる物資を置いておきたい。そしてその情報を主要都市のランドマークに残しておきたい」

## A. 沖縄の秘蔵の補給基地（1 か所、どのゲームでも同じ場所）
- 場所: 沖縄本島の自衛隊の施設（那覇の駐屯地・基地など、区域に敷地が建っているもの）の中。建っていなければ、那覇近くの大きな施設の敷地に置く。理由と場所を PROGRESS.md に
- **弾薬 100,000 発**: 補給場所（07c の補給箱・駐屯地と同じ仕組み）として扱い、B で受け取る。プレイヤーの所持上限（150）はそのまま。基地から本拠や駐屯地へ運ぶ手段（遠征・駐屯地の補給線の行き先にできる、など）を最小限で用意する。100,000 という数がセーブ・UI・台帳で壊れないこと
- **耳 10,000**: 金庫（07d-2f の鍵の仕組み）を探索すると一度だけ手に入る。所持品に入り、本拠で納品される
- **最強の生存者**: 基地の奥の部屋に潜伏者として 3〜5 人。会話すると雇用候補になる。4 つの能力はすべて最大（10）、専用の特性（例:「元特殊部隊」: 防衛・遠征の成果が大きい／「元研究者」: 研究が大きい）、**契約金と賃金は最低**。雇うと 05 の規則どおり本拠へ向かう（移動の扱いは 05 に合わせる。沖縄から本拠までの帰り道をどう扱うか決めて PROGRESS.md に）
- 一度取ったものは二度と出ない（セーブに残す）。新規ゲームのたびに同じ中身がある
- 数値はすべて `src/data/` に置く（例: `BALANCE.okinawa`）。`02_systems_spec.md` に節を足す

## B. 主要都市の名所に残る手がかり
- 主要都市（政令指定都市と、名所のある主な都市: 札幌・仙台・東京・横浜・名古屋・大阪・京都・神戸・広島・福岡 など 10 か所程度）の名所の敷地の入口付近に、**読める手がかり** を置く（例: 掲示板の貼り紙、ノートの切れ端、壊れた無線機の録音）。E で読む
- 中身は崩壊直後の記録として書く（例:「自衛隊の最終輸送は那覇へ向かった。物資と精鋭は沖縄に集めたらしい」「鹿児島新港から船が出ていた」）。各地で少しずつ違う文にし、読み進めると全体が見えるようにする。文は `ja.ts` に置く
- 1 つ読むと、戦略地図の沖縄に「噂」の印と短い説明が出る。2 つ以上読むと補給基地のおおよその場所（セル）まで分かる。読んだかどうかはセーブに残す（08 の `markSeen` と同じ仕組みでよい）
- 手がかりは名所の表（`src/data/landmarks/*.ts`）に「手がかりを置く」印を足す形にして、名所の生成のコードを地方ごとに触らない。**慰霊の名所（原爆ドーム）には置かない**
- 08 のチュートリアル・ヒントの仕組みに 1 行ヒントを足す（最初の手がかりを読んだとき「鹿児島新港から沖縄航路で渡れる」）

## D. 軍艦島（端島）も同じ扱いにする
発注者の要望: 「軍艦島も同様の扱いにできる？」
- 端島は長崎市のセル 23901 の区域の南端近く（区域の座標でおよそ x 165, z 951）。縮めると 48×16m ほどで、区域データでは海になっている可能性が高い。L8 が軍艦島の名所を作っていればそれを使い、なければ島（岸壁と高層アパート群の廃墟）を区域の海の中に作る。**歩いては渡れない**ので、長崎港側の岸に船着き場を置き、E で船に乗ると島の船着き場へ移る（ゲーム内 1 時間が過ぎる）。島からも同じ方法で戻れる
- 報酬は沖縄と役割を分ける: **建築資材の大量備蓄**（木材・金属・セメント・部品・燃料 各 10,000、医薬品 1,000 など。`BALANCE` に置く）と、**最強の生存者 2〜3 人**（建築・工作に強い専用の特性。契約金・賃金は最低）。資材は本拠の容量を超えるので、島に「補給場所」として残し、遠征・駐屯地の補給線の行き先として運び出せるようにする（沖縄の弾薬と同じ仕組みを使う）
- 手がかり: 九州の名所（大浦天主堂・旧グラバー住宅・福岡タワー・熊本城など 3〜4 か所）に、軍艦島を指す別の手がかりを置く（例:「端島の古いアパートに資材を集めて籠城している人がいるらしい」）。読むと戦略地図の長崎のセルに「噂」の印
- 一度取ったものは二度と出ない（セーブに残す）。受け入れ基準の e2e に「手がかり → 船で島へ → 資材を受け取る・生存者を雇う → 戻る」を足す

## C. 遊びの約束
- 発注者の意図は **圧倒的なメリット**。弱めない。09 で全体の釣り合いを見るときも、沖縄の報酬は「遠くて危険な代わりに圧倒的」という位置づけのまま残す
- 沖縄の弾薬・軍艦島の資材で本土の経済が無意味になる点は、09 の調整の対象外（発注者の判断）

## 受け入れ基準
- 新規ゲームから（デバッグで移動を早めてよい）: 手がかりを 2 つ読む → 戦略地図に沖縄の補給基地のセルが出る → 鹿児島新港から沖縄航路で渡る → 基地で B で弾薬を受け取る・金庫で耳 10,000 を得る・最強の生存者に会って雇う → 本拠に戻ると納品・生存者の到着、までを e2e で通す
- セーブ・ロードをまたいで、読んだ手がかり・取った物資・雇った生存者が保たれる（単体テスト）
- `npm run check`・`npm run build`・関係する e2e が通る
