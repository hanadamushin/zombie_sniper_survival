# L10 普通の橋と、残りの長い橋

L9 が橋の名所を端から端まで作り直し、吊り橋・斜張橋・アーチ橋・桁橋を組み立てる共通の部品（`src/gen/buildings/defs/landmark/bridge.ts`）と、区域の土手を橋に置き換える仕組み（`src/gen/real/bridges.ts`）を作りました。
あなたの仕事は、その部品を使って **(A) 普通の川・海を渡る土手を桁橋に替える** ことと、**(B) 残っている長い連続橋（瀬戸大橋・しまなみ海道）を作る** ことです。

## 作業の前提（毎回最初に確認。発注者の許可済み）

- このセッションは GitHub リポジトリ `hanadamushin/zombie_sniper_survival` へ**プッシュできる状態**で作業する。作業ディレクトリにリポジトリが無い、または読み取り専用でしか複製できない場合は、**最初に**リポジトリを書き込み権限つき（push）でセッションに追加し、複製してから作業を始めること。**発注者はこの追加とプッシュを事前に許可している**（このプロンプト自体が発注者からの指示）
- 作業の最後に、指定のブランチへプッシュしたうえで、`git ls-remote` でリモートのブランチがローカルのコミットと一致することを確かめてから終える。プッシュできないまま終えない
- e2e の前に `pkill -f "vite preview"` を実行する（古いサーバが古いビルドを返すことがある）。e2e は全件で 1 時間を超えるので、流すのは名所の spec と `e2e/realmap*.spec.ts` だけでよい（全件は取りまとめ役が流す）

## A. 普通の橋（取りまとめ役の判断: L9 の提案どおり行う）
- 区域データの道路・鉄道の橋の区間のうち、**区域で幅 30m 以上の川・海を渡るもの** を、土手から桁橋に替える（橋脚つきの桁。川の上は水面が見え、船の通る高さは要らない）。30m 未満の小川・水路は土手のまま
- 全国の対象の数と、セルあたりの最大を先に数え、性能（三角形・ドローコール）の見積もりを PROGRESS.md に書いてから始める。普通の橋は同じ形の部品をまとめて描き、1 区域でドローコールが増えすぎないこと
- 境界をまたぐ橋は、L9 の明石海峡大橋と同じく両側の区域が自分の分を作り、境界で高さが一致すること
- L9 の既知の制限（橋の下の水面を弾と視線が通らない）は、普通の橋では避ける（桁の下を空ける。土台で持ち上げない）。直せるなら L9 の名所の橋も同じ方法に替える

## B. 長い連続橋
- **瀬戸大橋**（下津井瀬戸大橋・櫃石島橋・岩黒島橋・与島橋・北備讃瀬戸大橋・南備讃瀬戸大橋。吊り橋・斜張橋・トラスの組み合わせ）と **しまなみ海道**（少なくとも来島海峡大橋の 3 連の吊り橋、多々羅大橋、因島大橋）を、L9 の部品で 1 橋 1 行の表で作る。島々は区域にあればその上を道路が通る。海のセルにかかる部分は作れないので、作れた範囲と作れなかった範囲を PROGRESS.md に表で
- 主塔・径間の数は実物どおり（L9 と同じ約束）

- 普通の橋の多い区域・長い橋の区域で性能 3 指標が予算内
