# 02 地図データ・感染シミュレーション

あなたは日本の地図データと感染拡大シミュレーション、そして戦略層（日本地図画面）の担当です。
このゲームでは「どこにゾンビが何体いるか」がすべてこのシミュレーションから決まります。

## 読むもの
- `CLAUDE.md`、`docs/PROGRESS.md`
- `docs/02_systems_spec.md` §2（全部）、§1 のセル間移動
- `docs/01_game_design.md` §2・§5
- `docs/04_architecture.md` §5 の `WorldState`

## ゴール（M1）
新規ゲームで、日本地図上に0〜90日の感染拡大がタイムラプス再生され、スタート地点の候補3つから選んで開始できる。
ゲーム中は毎日シミュレーションが1ステップ進み、地図で確認できる。

## 実装範囲

### A. グリッド生成（`tools/build-grid.ts` → `public/data/grid.json`）
- 約10km 正方セル。陸地判定は npm の `world-atlas`（Natural Earth 由来）の日本ポリゴンを使う。離島は主要なもの（沖縄本島、佐渡、淡路、対馬など）が入れば十分
- 人口: **ネットワークから統計データが取れなくても完成できること**。まず外部の人口メッシュ取得を試してよいが、失敗したら即座に次の方法へ:
  主要都市の表（市名・緯度経度・人口、上位300市程度をあなたの知識から作成し `tools/data/cities.ts` に置く）を、都市規模に応じた半径のガウス核でセルに配分し、残りの人口を平地に薄く撒く。総人口が約1.25億になるよう正規化
- 山地: 標高データがなければ「海岸と都市からの距離＋ノイズ」で近似してよい。ただし日本アルプス・北海道中央部などが mountain になる程度の補正テーブルは入れる
- 交通ハブ（新幹線主要駅・主要空港のあるセル）と接続関係、国際ハブ5か所、8地方・都道府県の割り当て
- 出力は小さく（配列の構造体、数値は丸める。目標 < 300KB）

### B. 感染シミュレーション（`src/sim/world/infection.ts`）
- 純関数 `stepInfection(cells, grid, day, extras, rng)`。ビルド時（`tools/run-infection.ts`）とゲーム中の両方から同じ関数を呼ぶ
- 仕様は §2.2 のとおり。パラメータは `data/balance.ts`
- 事前計算: 3シナリオ × 0〜90日。90日目の完全な状態と、日次の Z スナップショット（対数8bit量子化）を `public/data/infection_<n>.bin`（または base64 JSON）に出力
- **結果を自分の目で検証すること**: 90日目に「大都市圏は壊滅、地方都市は高密度、山間・離島に低密度地帯が残る」になっているか、地図を PNG に書き出して確認する。全国が均一に真っ赤、またはほとんど広がらない場合はパラメータを調整し、`02_systems_spec.md` を更新

### C. ゲーム中の世界システム（`src/sim/world/`）
- `dayStarted` で `stepInfection` を1回。討伐による Z 減少、本拠・駐屯地の誘引を反映
- 本拠セルへの流入量を `world.hordeMeter` に累積（大群の発生処理そのものは 06 の担当。ここでは値を積むだけ）
- セル → 戦術パラメータの導出関数（§2.3: active 上限、種類比率、危険度）を純関数で提供
- スタート地点候補の抽出（§2.4）
- 移動: `travel` コマンド、経路探索（陸続き、山地コスト）、時間経過、到着時に `player.cell` 更新とイベント発火。移動中の遭遇イベントは枠だけ

### D. 戦略地図 UI（`src/ui/world/`）
- Canvas 2D。表示切替: ゾンビ密度／物資／人口（崩壊前）。未踏セルは intel に応じて情報をぼかす
- パン・ズーム、セルのホバー情報、現在地、移動先の指定（経路と所要時間を表示して確定）
- オープニングのタイムラプス（スキップ可）→ 候補3つの選択画面

### E. テスト
- 決定性（同シード同結果）、人口の保存（S+Z+死亡が pop0 を超えない）、海セルへ拡散しない、事前計算データとゲーム内継続が連続する

## やらないこと
戦術マップの生成、駐屯地の設置処理、遠征（05）、大群の発生（06）。

## 受け入れ基準
- `npm run data` で地図と感染データが再生成でき、生成物がコミットされている
- 新規ゲーム → タイムラプス → 候補選択 → 開始、が通る
- M キーで地図を開き、隣接セルへ移動を指示すると時間が進んで現在地が変わる
- 東京・大阪・名古屋の都市圏が高密度、候補地が田舎になっている（スクリーンショットで確認）
- 1日分の `stepInfection` が 5ms 未満
