# 05. ロードマップ

## マイルストーン

| # | 名称 | 遊べる状態 | 担当プロンプト |
|---|---|---|---|
| M0 | 土台 | 空の3D画面が起動し、時間が進み、セーブできる | 01 |
| M1 | 地図 | 日本地図に感染拡大が再生され、スタート地点を選べる | 02 |
| M2 | 射撃場 | 作戦区域を歩き、スコープで狙撃し、耳を拾える（**ここで手触りを確認**） | 03, 04 |
| M3 | 共同体 | 生存者を雇い、仕事を割り振り、経済が回る | 05 |
| M4 | 砦 | 壁・堀・建物を建て、襲来を防衛する。駐屯地を置ける | 06 |
| M5 | 文明 | 技術ツリーが進み、分岐を選び、建国宣言できる | 07 |
| M6 | 仕上げ | UI/UX・音・チュートリアルが整う | 08 |
| M7 | 調整 | 通しプレイで破綻がなく、難易度曲線が妥当 | 09 |
| M8 | スマホ | タッチで遊べる（任意） | 10 |

## セッション実行順と依存関係

```
01 基盤 ──┬─▶ 02 地図・感染 ──────────────┐
          └─▶ 03 戦術3D ─▶ 04 狙撃・ゾンビ ─┴─▶ 05 共同体 ─▶ 06 建築・防衛 ─▶ 07 技術・進行 ─▶ 08 UI・音 ─▶ 09 調整・QA ─▶ (10 スマホ)
```

- 02 と 03 は 01 の後なら並行可能（触るディレクトリが別）。それ以外は直列を推奨
- 各セッションは開始時に `docs/PROGRESS.md` を読み、終了時に追記する
- M2 完了時点で一度プレイして、狙撃の手触りに違和感があれば 04 を再実行（調整指示つき）してから先へ進むのが最も効率的

## 各セッションの完了定義（共通）

1. `npm run check` が通る
2. `npm run build` が通り、`npm run dev` で起動してコンソールエラーがない
3. 受け入れ基準（各プロンプト記載）を自分で確認した（可能なものは Playwright かテストで）
4. `docs/PROGRESS.md` に追記した
5. 仕様と違う実装にした箇所は該当 docs を更新した
6. コミットしてプッシュした
