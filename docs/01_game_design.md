# 01. ゲームデザイン

## 1. コンセプト

> **「一発で仕留め、歩いて耳を拾い、その耳で国を建てる。」**

- ジャンル: 一人称スナイパーシューティング × サバイバル建国シミュレーション
- プラットフォーム: PCブラウザ（キーボード＋マウス）。スマホは後回しの任意対応
- 1プレイの想定: 序盤〜建国宣言まで 8〜15 時間（セーブ可）。その後はエンドレス
- 体験の柱
  1. **精密狙撃の手応え** — 弾道落下・着弾遅れ・呼吸・ゼロイン。遠くの1体を静かに仕留める快感
  2. **耳の経済** — 撃つだけでは稼げない。死体まで歩いて耳を拾う「回収のリスク」が毎回の判断を生む
  3. **人に任せる建国** — 生存者を雇い、仕事を割り振り、拠点が自律的に育つのを眺める
  4. **一長一短の選択** — 都会か田舎か、壁か堀か、畜産か水耕か。正解がひとつに定まらない

## 2. 世界観

- 文明は崩壊。法定通貨は紙屑になり、**ゾンビの耳** が通貨になった（討伐の証明であり、偽造できず、供給量が治安と連動するため）。単位は「耳（みみ）」。ゾンビ1体から2耳
- プレイヤーは任務で過疎地にいたため感染拡大を免れた狙撃手。装備はサプレッサ付きボルトアクション狙撃銃、ナイフ、弾薬100発
- ゲーム開始は発生から **90日目**。オープニングで日本地図上の感染拡大（0〜90日）をタイムラプス再生し、その結果がそのままゲームの初期状態になる
- トーン: 静かで乾いた終末。ホラー演出よりも「遠くから観察して決断する」緊張感を重視

## 3. ゲームの3層構造

| 層 | 視点 | やること |
|---|---|---|
| **戦術層**（リアルタイム3D） | 一人称 | 狙撃、耳の回収、探索、ナイフ戦、拠点防衛 |
| **指揮層**（同じ3Dマップを俯瞰） | 見下ろし | 建築の設計図配置、生存者の仕事割り振り、研究・経済の管理 |
| **戦略層**（日本地図2D） | 地図 | 移動先の選択、駐屯地の設置、調達隊の派遣、感染状況の把握 |

- 戦術層と指揮層は **同じ場所の同じ時間** を別カメラで見ているだけ（Tabで切替）。指揮中も時間は流れる（一時停止・倍速可）
- 戦略層の1マス（約10km四方のセル）に入ると、そのセルを代表する **作戦区域（約1km四方の3Dマップ）** がシードから生成される

## 4. コアループ

```
        ┌──────── 狙撃して倒す ───────┐
        │                              ▼
   弾薬・装備を補給              耳を歩いて回収（リスク）
        ▲                              │
        │                              ▼
   拠点・駐屯地が育つ ◀── 耳で人を雇い、食料を買い、建てる
        │
        └─▶ より危険で豊かな地域（都市）へ進出 ─▶ 先頭へ
```

- 短期（数分）: 観測 → 測距 → 射撃 → 回収
- 中期（1ゲーム日 = 実時間24分）: 昼に稼ぎ・探索、夜に防衛。給料と食料の支払い
- 長期（数十日）: 技術の時代を進め、駐屯地網を都市へ伸ばし、建国宣言へ

## 5. 都会と田舎

感染拡大シミュレーションの結果、セルごとにゾンビ数・残存物資・潜伏生存者数が決まる。

| | 田舎 | 郊外 | 都市 |
|---|---|---|---|
| ゾンビ | 少ない。**狩り尽くせる**（＝安全地帯にできる） | 中 | 事実上無限。常に湧く |
| 耳の稼ぎ | すぐ枯れる | 安定 | 無尽蔵だが囲まれやすい |
| 物資 | 木材・農地向き。部品や医薬品は乏しい | 中 | 金属・部品・医薬品・弾薬が豊富 |
| 生存者 | 少数（農業向きが多い） | 中 | 多い（知識型が多い） |
| 大群の襲来 | まれ | 時々 | 頻繁 |

- スタート地点は **人口密度の低いセルからランダム**（3候補から選択）。物語設定とも整合し、序盤の学習時間を確保する
- 田舎は安全だが稼ぎが枯れる → 都市方面へ駐屯地を伸ばす動機になる
- 都市隣接セルの拠点は大群の移動経路になりやすい（シミュレーションのゾンビ移動がそのまま襲来になる）

## 6. 狙撃（最重要の手触り）

- 腰だめでは当たらない。**右クリックでスコープ**、ホイールで倍率、Shiftで息止め
- 弾は即着弾ではなく **実弾道**（初速・重力落下・飛翔時間）。ミルドットで測距し、ゼロイン距離を合わせるか、レティクルで見越す
- 姿勢（立ち/しゃがみ/伏せ）と移動直後・スタミナで照準の揺れが変わる
- 部位ダメージ: 頭＝即死、胴＝複数発、脚＝転倒して這う
- 1発が直線上の複数体を貫通（技術で貫通数増）。「並んだ瞬間を待つ」遊び
- サプレッサ付きなので **銃声でゾンビは寄ってこない**。ただし近くで仲間が倒れるのを見たゾンビは警戒し、プレイヤーを視認すると追ってくる
- 倒したゾンビの死体に近づいて E で耳を2つ回収。死体は一定時間で消える（耳も消える）ので、撃ちっぱなしは損
- ナイフ: 無音の近接。背後からは一撃。弾の節約と緊急用

上達の余地: ヘッドショット率、1発あたりの耳（貫通）、回収ルート取り、射点（見張り塔・屋上）の選定。

## 7. ゾンビ

| 種類 | 特徴 | 役割 |
|---|---|---|
| 歩行型 | 遅い。大多数 | 基本の的・耳の供給源 |
| 走行型 | 速い。細身で当てにくい | 回収中の脅威、狙撃の難度 |
| 肥大型 | 頑丈。壁への攻撃力が高い。頭以外はほぼ効かない | 拠点防衛での最優先目標 |
| 這行型 | 草むらで見えにくい。脚を撃たれた個体もこれになる | 回収時の不意打ち |

- 夜は視認距離が伸び、移動が速くなる（夜は拠点で守る、が基本リズム）
- 堀は渡れない。落ちた死体が溜まると橋になる（→清掃が必要）

## 8. 生存者

各地に隠れている生存者を発見・救出・勧誘して雇う。

**ステータス（1〜10）**

| ステータス | 意味 |
|---|---|
| 運動 | 土木作業・戦闘・調達の適性 |
| 知識 | 研究・工作・医療の適性、農業の一部 |
| 速度 | あらゆる作業の稼働スピード（成果量の倍率） |
| スタミナ | 食事量あたりの稼働量（高いほど少食で長く働く） |
| コスト | 1日あたりの賃金（耳）。能力合計と性格から決まる |

変動値として **士気**（食事・賃金・住環境・仲間の死で上下）と **体力/負傷/感染** を持つ。
加えて1人1つの **特性**（例: 元自衛官＝防衛+、農家出身＝農業+、強欲＝賃金+30%、忠実＝賃金遅配に耐える、臆病＝調達の帰還率+だが防衛−）。

**仕事**

| 仕事 | 主な適性 | 成果 |
|---|---|---|
| 農業（畜産含む） | 運動＋知識 | 食料を生産し、**プレイヤー（共同体）に売る** |
| 防衛 | 運動 | 見張り・壁上からの迎撃・襲来時の戦闘 |
| 物資調達 | 運動 | 指定セルへ遠征し物資・生存者情報を持ち帰る。**持たせる武器で帰還率が変わる** |
| 建築 | 運動 | 設計図どおりに壁・堀・建物を作る、修理、堀の清掃 |
| 研究 | 知識 | 研究ポイントを生む |
| 工作 | 知識＋運動 | 弾薬・武器・道具の製造 |
| 医療（技術で解禁） | 知識 | 負傷・感染の治療 |

- 生存者の行動は **ルールベースAI**（仕事ごとの状態機械＋効用による優先度選択）。拠点内は3D上で動く姿を描写、遠征や他セルは数値処理のみ
- プレイヤーは個別に細かく命令しない。「誰に何の仕事を割り振るか」と「設計図・優先度」を決める

## 9. 経済

- 収入: ゾンビの耳（狙撃・防衛での討伐分の回収）、調達隊の持ち帰り、交易（技術）
- 支出: 賃金（毎日）、**食料の購入**、雇用契約金、弾薬・建築資材の一部
- 食料: 農業担当の生存者は固定給ではなく **作った食料の売上** で暮らす。共同体の配給分をプレイヤーが市場価格で買い上げる。価格は需給（備蓄日数）で変動。自前の農家がいない序盤は、地図上の農村集落（中立NPC）から割高で買う
- 賃金未払い・食料不足は士気低下 → 離反・脱走
- 耳は田舎では枯れる有限資源、都市では危険と引き換えの無限資源。これが進出の原動力

## 10. 拠点・建築

- 指揮層でグリッドに **設計図** を置く → 建築担当が資材を運んで建てる
- **壁**: 木柵 → 土塁 → 鉄板壁 → コンクリート壁。耐久がゾンビの攻撃で削られ、0で破壊。修理可
- **堀**: 掘るのに時間がかかるが資材不要。ゾンビは渡れず、切れ目へ誘導される → 射線の通る「キルゾーン」を設計できる。死体が溜まると渡られる
- **門**: 生存者の出入り口。弱点になる
- **見張り塔**: プレイヤーの射点、防衛担当の射程延長、襲来の早期発見
- 機能建物: 司令部、住居、農地、畜舎、倉庫、工房、研究所、診療所、食堂、市場、無線塔、発電機、兵舎、記念碑 など（技術で解禁、段階アップグレード）
- **襲来**: 周辺セルのゾンビ移動量と拠点の規模に応じて、夜間の小規模接近と数日おきの大群が来る。プレイヤーは塔から狙撃で支援するのが防衛戦の華

## 11. 駐屯地

- 拠点以外のセルに設置する前線基地。条件: そのセルのゾンビを一定以下に減らす＋耳と資材＋常駐1名以上
- 機能: **弾薬補給**、安全な休息、ファストトラベル、調達隊の行動範囲拡大、周辺セルの監視
- 駐屯地は簡易プレハブ（本拠のような自由建築はなし）。等級を上げると防御・備蓄上限が増える
- 本拠から各駐屯地へは日次で自動補給（距離に応じた遅延と上限）

## 12. 技術の発展

- 5カテゴリ（防衛建築 / 兵器 / 農業・食料 / 科学・医療 / 社会・経済）× 4時代（生存期 → 定住期 → 再建期 → 復興期）
- 研究担当の生む研究ポイントを、カテゴリごとの配分比率に従って **並行で** 進める（時間経過で各カテゴリが発展）
- 各カテゴリに **排他分岐**（片方を選ぶともう片方は取れない）。詳細は `03_tech_tree.md`

## 13. 目的と敗北

- **勝利: 建国宣言** — 復興期に到達し、人口60人・駐屯地6か所（3地方以上）・いずれかの到達技術（ワクチン／要塞都市／連邦憲章）を満たして「政府庁舎」を建てる。到達技術でエンディングが変わる。以後はエンドレス
- **敗北**: 司令部が破壊される、またはプレイヤーが死亡した時点で共同体に誰もいない
- プレイヤー死亡（共同体あり）: 3日後に拠点で復帰。所持していた耳と弾を失う
- 難易度3段階（ゾンビ数・襲来頻度・照準の揺れ・風の有無）

## 14. スコープ外（やらないこと）

- マルチプレイ、他の人間勢力との戦闘、複雑な物流の手動管理、車両の運転操作（移動時間短縮の技術としてのみ扱う）、外部アセットに依存した高精細グラフィック
