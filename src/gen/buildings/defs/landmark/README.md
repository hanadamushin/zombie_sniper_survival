# Landmark buildings (R1–R8)

One folder per region (`hokkaido/`, `tohoku/`, … `kyushu/`). Each region session may add up to three
landmark types (castle, tower, great temple, bridge tower…) as 07d blueprints (`docs/buildings_guide.md`),
category `landmark`, id `landmark.<variant>`, listed in `src/gen/buildings/catalog/landmark_<region>.ts`.
They are placed at the shrunk real position by a `POI` (see `docs/realmap_guide.md` §7).
